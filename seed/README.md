# seed/

Starting material, **not product code**. `alertalergo-port/` is the eSpeak NG port as it runs inside the AlertAlergo
V3 firmware (commit `19787f2`), copied unchanged with its relative paths. Provenance and what each file is:
[`../docs/Ideia/origem-do-porte.md`](../docs/Ideia/origem-do-porte.md).

It is evidence for the specification. As the FSD is written and the component is built (`components/`, `firmware/`),
code moves out of here with its tests; this directory disappears when it is empty. It is not built by CI.
